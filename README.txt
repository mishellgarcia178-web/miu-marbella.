MiU Marbella García — Auditoría y Contaduría Pública

Incluye las nuevas secciones «Trabajos en grupo» y «Biblioteca de materiales», además del rediseño de «Mis notas».

CÓMO ABRIR
1. Abrí index.html en Chrome o Edge.
2. Entrá al prototipo.
3. Seleccioná las nuevas secciones en el menú de estudiante.

FUNCIONES
- Grupos: crear un trabajo, definir integrantes, asignar actividades, marcar actividades realizadas, ver avance.
- Biblioteca: buscar, filtrar por materia, guardar favoritos, leer fichas, crear notas propias.
- Notas: calificaciones ficticias por curso, visualización de barras y calculadora de nota final.

AVISO
Es un prototipo académico no oficial. No contiene autenticación real ni base de datos Supabase.
Los datos se guardan localmente en el navegador y no se comparten entre dispositivos.
Los materiales son textos de ejemplo, no archivos subidos ni materiales oficiales.
Para GitHub, subí index.html y este README.
